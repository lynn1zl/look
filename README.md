# 외관표 니니닝! 🐰

이미지를 끌어다 놓기만 하면 완성되는 캐릭터 외관표. 만든 외관표는 PNG로 저장하거나 클립보드에 바로 복사할 수 있어요.

## 기능

- **2인 · 1인**: 기본은 2인 좌우 대칭 배치, 상단에서 1인으로 전환 (넣어 둔 내용은 그대로 유지). 좌우 캐릭터 바꾸기 버튼
- **캐릭터마다**
  - 전신 이미지 칸 (세로)
  - 두상 이미지 칸
  - 머리색 · 눈색: 색 칩을 눌러 컬러판에서 고르거나 컬러코드(`#RRGGBB`, `#RGB`, `rgb(...)`)를 직접 입력. Chrome · Edge에서는 스포이트로 화면 속 그림에서 바로 색 뽑기
  - 주요 특징 (여러 줄)
  - 이름 · 성별 · 나이 · 키
- **가운데**: 페어명 · 관계성
- **이미지 넣기**: 끌어다 놓기, 칸 클릭, `Ctrl/⌘ + V` 붙여넣기 (마우스를 올려 둔 칸 → 빈 칸 순서). 여러 장을 한 번에 놓으면 빈 칸에 차례로
- **이미지 위치**: 끌어서 보이는 부분 옮기기, `+ / −` 또는 휠로 확대, ‘맞춤’으로 잘리지 않게 전체 보기
- **디자인**: 배경(화이트 · 클라우드 · 다크), 포인트 색, 니니닝 로고 표시 여부
- **저장**: PNG 1× · 2× · 3×, 클립보드 복사, 모바일은 공유 시트. 빈 칸의 안내 문구와 빈 정보 칩은 저장 이미지에서 자동으로 빠짐
  - 파일 이름: `[외관닝]페어명_날짜.png`
- **자동 저장**: 이 브라우저(IndexedDB)에만 저장 · 서버로 보내지 않음. ‘작업 파일로 내보내기 / 불러오기’로 다른 기기에 옮기기
- **반응형**: 데스크톱은 화면 맞춤 · 확대/축소, 휴대폰은 세로로 쌓인 편집 화면 (저장 이미지는 항상 원래 배치)

## 배포 (GitHub Pages)

빌드 과정 없는 정적 사이트예요.

1. 이 폴더의 파일을 저장소 루트에 올리기
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 선택
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열림
