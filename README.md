# 외관표 니니닝! 🐰

이미지를 끌어다 놓기만 하면 완성되는 캐릭터 외관표. 만든 외관표는 PNG로 저장하거나 클립보드에 바로 복사할 수 있어요.

## 기능

- **2인 · 1인**: 기본은 2인 좌우 대칭 배치, 상단에서 1인으로 전환 (넣어 둔 내용은 그대로 유지). 좌우 캐릭터 바꾸기 버튼
- **캐릭터마다**
  - 전신 이미지 칸 (세로) + 두상 칸 2개
  - 머리색 · 눈색: 색 칩을 누르면 **단색 · 직선 · 원형 · 투톤** 그라데이션 중 고르고, 컬러판이나 컬러코드(`#RRGGBB`, `#RGB`, `rgb(...)`)로 입력. 직선 · 투톤은 방향 조절. Chrome · Edge에서는 스포이트로 화면 속 그림에서 바로 색 뽑기
  - 눈색 두 칸(오드아이): ‘+ 눈색 추가’ 또는 눈색 칩의 스위치로 켜고 끄기. 켜면 왼쪽 눈 · 오른쪽 눈으로 이름이 바뀌고 세 색이 한 줄에
  - 기본 색: A는 금색 머리 · 레몬색 눈, B는 갈색 머리 · 초록색 눈
  - OK · NG: 캐릭터로 되는 것 · 안 되는 것 한 줄씩 (비우면 저장 이미지에서 빠짐)
  - 주요 특징 (여러 줄)
  - **특징 직접 그리기**: 주요 특징 카드의 ‘+ 특징 그리기’로 원 · 왼손 · 오른손 · 왼쪽 귀 · 오른쪽 귀 · 빈 칸 그림판을 최대 4개 넣고, 마우스 · 터치로 반지 · 피어싱 · 점 위치 등을 바로 그리기 (펜 색 · 굵기 · 지우개 · 되돌리기, 원은 ‘기본 얼굴’도 가능). 칸 이름은 눌러서 바꾸기
  - 이름 옆 동그라미: A · B 글자 (눌러서 바로 바꾸기)
  - 이름 · 성별 · 나이 · 키 · 직업
- **가운데**: 페어명 · 페어 태그, 서로를 어떻게 생각하는지 (A → B, B → A 화살표). 상단 ‘관계성’ 버튼으로 켜고 끄기 — 끄면 가운데 폭이 페어명만큼만 남음
- **커미션 출처**: 오른쪽 아래에 입력 (비우면 저장 이미지에서 빠짐)
- **이미지 넣기**: 끌어다 놓기, 칸 클릭, `Ctrl/⌘ + V` 붙여넣기 (마우스를 올려 둔 칸 → 빈 칸 순서). 여러 장을 한 번에 놓으면 빈 칸에 차례로
- **이미지 위치**: 끌어서 보이는 부분 옮기기, `+ / −` 또는 휠로 확대, ‘맞춤’으로 잘리지 않게 전체 보기
- **디자인**: 배경(화이트 · 클라우드 · 다크), 포인트 색
- **저장**: PNG 1× · 2× · 3×, 클립보드 복사, 모바일은 공유 시트. 빈 칸의 안내 문구와 빈 정보 칩은 저장 이미지에서 자동으로 빠짐
  - 파일 이름: `[외관닝]페어명_날짜.png`
- **자동 저장**: 이 브라우저(IndexedDB)에만 저장 · 서버로 보내지 않음. ‘작업 파일로 내보내기 / 불러오기’로 다른 기기에 옮기기
- **반응형**: 데스크톱은 화면 맞춤 · 확대/축소, 휴대폰은 세로로 쌓인 편집 화면 (저장 이미지는 항상 원래 배치)

## 배포 (GitHub Pages)

빌드 과정 없는 정적 사이트예요.

1. 이 폴더의 파일을 저장소 루트에 올리기
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 선택
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열림
