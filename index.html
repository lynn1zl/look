칸을 눌러 바로 입력하세요 · 이미지는 끌어다 놓기, 클릭, Ctrl/⌘ + V 붙여넣기

사용 방법

  • 글자 — 외관표 위의 칸을 눌러 바로 입력해요. 빈 칸은 저장할 때 안내 문구 없이 깔끔하게 비워져요.
  • 이미지 — 전신 · 두상 칸에 파일을 끌어다 놓거나, 눌러서 고르거나, 복사한 이미지를 Ctrl/⌘ + V로 붙여넣어요. 칸 위에 마우스를 올린 채 붙여넣으면 그 칸에 들어가요.
  • 이미지 위치 — 이미지를 끌어서 보이는 부분을 옮기고, 휠이나 + / − 버튼으로 확대해요. 맞춤을 누르면 잘리지 않게 전체가 보여요.
  • 색 — 동그란 색 칩을 누르면 컬러판이 열려요. 컬러코드(#RRGGBB)를 직접 고쳐 써도 돼요. 스포이트 버튼이 보이면 화면 속 그림에서 바로 색을 뽑을 수 있어요.
  • 2인 · 1인 — 위쪽에서 인원을 고르고, 버튼으로 좌우 캐릭터를 바꿔요.
  • 커미션 출처 — 외관표 오른쪽 아래 칸에 적어요. 비워 두면 저장 이미지에 나오지 않아요.
  • 저장 — ‘이미지 저장’은 PNG 파일로, ‘복사’는 클립보드로 보내요. 작업 내용은 이 브라우저에 자동 저장되고, 다른 기기로 옮길 땐 ‘작업 파일로 내보내기’를 써요.

넣은 이미지와 글은 서버로 보내지지 않고 이 브라우저 안에만 저장돼요.
